# Moj kraj skozi objektiv

Predloga za praktično nalogo pri predmetu **Multimedija**.

## Uporaba

1. Na GitHubu ustvari nov **Public repository**, npr. `moj-kraj-solkan`.
2. Razširi ZIP in v repozitorij naloži **vsebino mape**.
3. V mapi `images` zamenjaj vzorčne fotografije s svojimi.
4. Imena slik ohrani popolnoma enaka:
   `naslovna.jpg`, `foto1.jpg`, `foto2.jpg` ... `foto8.jpg`.
5. V `index.html` spremeni ime in opis kraja, naslove in opise fotografij,
   podatke o avtorju ter YouTube video.
6. Po spremembah izberi **Commit changes**.
7. Stran objavi: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Pravilna struktura repozitorija

```text
moj-kraj/
├── index.html
├── style.css
├── README.md
└── images/
    ├── naslovna.jpg
    ├── foto1.jpg
    ├── foto2.jpg
    ├── foto3.jpg
    ├── foto4.jpg
    ├── foto5.jpg
    ├── foto6.jpg
    ├── foto7.jpg
    └── foto8.jpg
```

### Fotografije

Uporabi lastne fotografije. Pred nalaganjem jih obdelaj in optimiziraj za splet:
JPG, sRGB, priporočeno največ približno 1920 px po daljši stranici.

**Pomembno:** `index.html` in `style.css` morata biti v osnovni mapi repozitorija,
mapa `images` pa neposredno poleg njiju.
